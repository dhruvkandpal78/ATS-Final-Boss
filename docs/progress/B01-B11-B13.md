# B01/B11-B13: runtime, API and verification

Status: implemented for local use; final checks continued 2026-09-28. Baseline: a0c2982dfdf2358c39b415c237eb4338eeb98de3.

Changed: src/app/server.py, scripts/doctor.py, pyproject.toml, .env.example, .github/workflows/ci.yml, .gitignore, tests/test_api.py, tests/test_pdf_forensics.py and integration-test markers.

Models load lazily in one persistent spawned process. A nonblocking capacity lock rejects concurrent analyses with 429; a 90-second deadline terminates the worker and removes the parent-owned temporary upload directory. There is no waiting queue. Inputs are validated before model work: JSON object, mutually exclusive text/PDF, strict base64, PDF signature, 5 MiB decoded file, 7 MiB request, 100,000 characters and 20 PDF pages. Upload reading has a socket timeout. Public errors exclude exception traces, paths and resume content. The server binds to loopback by default and serves only explicit frontend/license routes plus traversal-checked assets.

Doctor reports every required package, artifact/config hash and embedding config-cache presence. Importing the server does not load models or download weights. CI installs the development extra (including reportlab) and runs deterministic tests with integration tests excluded and network model downloads disabled. Generated PDF test files now live in temporary directories instead of modifying tracked fixtures.

Verification: API validation, serialization, error redaction, busy rejection, success/failure/timeout cleanup and static path traversal tests pass in the 73-test suite; see ENHANCEMENT_2026-09-26.md. The real isolated worker also completed a synthetic text request. JavaScript syntax, Python compilation and diff checks passed.

Limits: process termination is tested deterministically; the runtime is not a production web stack or an OS memory sandbox. Transport is JSON/base64, not multipart. Browser cancellation does not immediately stop server computation. Dependencies are not fully locked and artifact hashes are not signatures.
