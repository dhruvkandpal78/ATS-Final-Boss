# B02-B03: shared inference and truthful results

Status: implemented; baseline a0c2982dfdf2358c39b415c237eb4338eeb98de3.

Changed: src/core/analysis_service.py, src/core/schemas.py, src/inference.py, tests/test_inference_parity.py, tests/test_inference.py; HTTP adapter changes recorded separately.

The service now supplies both CLI and API results. It orders features, applies the saved scaler once and selects class 1 by estimator.classes_, including reversed class order. Policy triggers never rewrite the numeric output. Empty, corrupt, encrypted, image-only, mixed-page, page-limit and semantically truncated input cannot silently receive a complete clear verdict. Text has no PDF score and no invented combined score. Actual PDF findings preserve page/rectangle anchors where available. Keyword and direct structural/instruction signals can recommend review independently of model score.

Legacy compatibility aliases remain; clients should use schema_version 2.0, decision, score/score_kind, coverage, modules and findings. Legacy attack/clean strings are not candidate suitability labels. CLI JSON now serializes the actual contract and direct script invocation works.

Validation: scaler spy/reversed classes, API/CLI parity, rule-score separation, missing modalities and generated PDF coverage regressions. See full verification command and exit 0 in ENHANCEMENT_2026-09-26.md.

Limitation: saved model was trained with a synthetic PDF proxy and is uncalibrated for physical PDF evidence. Next: versioned real-PDF artifact contract and independent calibration/benchmark.
