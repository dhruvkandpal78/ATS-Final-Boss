# B04-B10: detector logic and research methodology

Status: implementation verified; research benchmarks pending. Baseline a0c2982dfdf2358c39b415c237eb4338eeb98de3.

Changed: src/data_prep/injector.py, splitter.py; src/modules/module_a.py, module_b.py, module_c.py; src/models/meta_classifier.py; src/evaluation/evaluate.py, evaluate_holdout.py, curves.py; related tests including keyword/PDF/semantic safety and source lineage.

- Generated variants retain source_id. Group-disjoint splits reject missing lineage; row ratios are approximate and stratification is not claimed.
- Keyword aliases use token boundaries and compiled expressions; token-start lookup replaces repeated prefix copies and handles newline/tab positions.
- Injection cues normalize compatibility/format characters and scope descriptive/quoted exceptions locally. Approximate LOO explanation work is capped at 64 selected units and omissions disclosed.
- PDF contexts close reliably; gray/RGB white text, opacity, trace bounds and actual OCG metadata are handled. Small image/background overlaps no longer exempt a whole span. Trace/finding counts are bounded. OCG presence is reported as incomplete coverage, not proof of malicious hidden content.
- Classifier training uses explicit optional XGBoost and one worker by default; folds respect minority-class size. Invalid labels/features fail early. The failing, misleading nested-CV diagnostic was removed; training does not publish test performance.
- Research feature extraction reuses supplied detectors and labels B as synthetic proxy. Degradation uses a fixed seeded validation-only subset with a comparable zero-budget baseline. Final holdout adapter requires real PDF paths, fails on incomplete scoring and does not write fictitious metrics.

Tests: synthetic source groups, aliases/whitespace, obfuscated and benign injection controls, real generated hidden PDFs, small-class training/save-load and deterministic evaluation helpers pass in the 73-test suite. No train/validation/test dataset was read or regenerated during this enhancement.

Primary API references checked for PDF changes: https://pymupdf.readthedocs.io/en/latest/document.html#get_ocgs and https://pymupdf.readthedocs.io/en/latest/functions.html#Page.get_texttrace .

Limits: no measured accuracy improvement; changed feature semantics invalidate reuse of old headline metrics. Existing quote/context rules can still have false positives/negatives. PDF visibility is heuristic. Next: version features and recalibrate only on training/validation before a frozen final benchmark.
