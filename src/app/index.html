STEP 01

Keyword Density

MODULE A · STATISTICAL

Rooted in spam-filtering theory, Module A measures how often skill keywords appear relative to the whole document. A natural résumé sits near the baseline; a stuffed one spikes far past the 95th-percentile threshold.

STEP 02

PDF Structure

MODULE B · FORENSIC

Module B ignores what you can see and interrogates the PDF byte-layer: 1-pt fonts, invisible render mode 3, zero-size bounding boxes, off-page coordinates, and hidden optional-content layers — the classic tricks for smuggling keywords past the eye.

STEP 03

Semantic Coherence

MODULE C · SEMANTIC + XAI

Using MiniLM sentence embeddings, a sliding window scores how smoothly meaning flows. Context-less jargon and LLM-obfuscated blurbs break the flow — and a direct-instruction detector flags prompt-injection footers outright. Leave-one-sentence-out attribution then highlights the exact culprit.

STEP 04

The Meta-Classifier

ENSEMBLE · DECISION

The three heterogeneous signals converge into a logistic-regression meta-classifier — trained only on a held-out validation split to prevent leakage. It outputs one calibrated probability: how likely this résumé is an adversarial attack.
