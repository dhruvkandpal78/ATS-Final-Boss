  1. 01Validate the input

    Accept pasted text or a PDF. Check size and page limits before processing.

  2. 02Extract the text

    Read available PDF text and record extraction gaps. Image-only pages are not processed with OCR.

  3. 03Inspect PDF structure

    Module B checks supported text traces for hidden or unusual rendering. This check is PDF-only.

  4. 04Check keyword patterns

    Module A measures skill-keyword density. A separate rule looks for sustained keyword repetition.

  5. 05Read semantic signals

    MiniLM measures sentence-window coherence. Separate lexical rules identify direct instruction-like cues.

  6. 06Score when supported

    Complete supported PDFs can receive an experimental classifier score. Text-only inputs have no validated model score.

  7. 07Return evidence for review

    Report findings, source context and coverage. Review policy stays separate from the score and hiring decisions.

      Methodology

      How to read an analysis.

      ATS Final Boss is a research prototype for detecting document manipulation signals. It supports human review and does not determine authenticity or hiring outcomes.

      Three complementary signals

      Module A examines keyword patterns in text. Module B examines supported structural properties in PDF files. Module C examines semantic changes and instruction-like content. Each result reports whether a module ran, was not applicable, or could not complete.

      Score and policy

      When a compatible model is available, the interface shows its returned score. The score is uncalibrated unless the service explicitly says otherwise. Review policy can recommend attention even when no model score is available. The two are never combined into an invented probability.

      Coverage and limitations

      Text input cannot be structurally analyzed as a PDF. Some PDFs may be encrypted, image-only, partially extracted, or outside detector support. The result lists these limitations beside usable findings. No detected signals is not proof of authenticity.

      Evaluation status

      A frozen external challenge flagged 100 of 1,000 publisher-assigned attack PDFs and left 900 unflagged after complete analysis. None of 100 original synthetic PDFs was flagged; that sample does not establish a below-2% false-positive rate. These controlled results do not establish real-world accuracy or downstream protection. Read the full experiment and uncertainty.

      Privacy and responsible use

      Content is sent to the application server for analysis. Send personal data only with authorization. A finding describes a document pattern, not a person’s intent, character or suitability.
