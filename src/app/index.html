      Methodology

      How to read an analysis.

      ATS Final Boss is a research prototype for detecting document manipulation signals. It supports human review and does not determine authenticity or hiring outcomes.

      Three independent signals

      Module A examines keyword patterns in text. Module B examines supported structural properties in PDF files. Module C examines semantic changes and instruction-like content. Each result reports whether a module ran, was not applicable, or could not complete.

      Score and policy

      When a compatible model is available, the interface shows its returned score. The score is uncalibrated unless the service explicitly says otherwise. Review policy can recommend attention even when no model score is available. The two are never combined into an invented probability.

      Coverage and limitations

      Text input cannot be structurally analyzed as a PDF. Some PDFs may be encrypted, image-only, partially extracted, or outside detector support. The result lists these limitations beside usable findings. No detected signals is not proof of authenticity.

      Evaluation status

      Current benchmark publication awaits validated artifacts with dataset, modality, split and run provenance. Historical prototype results do not establish performance of the current pipeline.

      Privacy and responsible use

      Content is sent to the application server for analysis. Send personal data only with authorization. A finding describes a document pattern, not a person’s intent, character or suitability.
